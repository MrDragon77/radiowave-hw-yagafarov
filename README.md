# Ослабление радиоволн в атмосфере: домашние задания

Выполнил: **Ягафаров Азат Рамилевич**, группа **М12-512С**, вариант **10**.

Расчётные задания к книге «Ослабление радиоволн в атмосфере». Каждое задание лежит в своей папке и устроено по шаблону курса: README с постановкой, методом, результатами и графиками, SOURCES.md, ответы на вопросы для защиты, программа, результаты и тест контрольного варианта 0.

| ДЗ-2 | Капли: от проницаемости воды к удельному затуханию | - |

## Структура

```
README.md              этот файл: список заданий
LICENSE                лицензия на код (общая)
requirements.txt       библиотеки Python (общие)
.github/workflows/     автоматическая проверка (pytest)
dz1/
  README.md            постановка, метод, результаты, графики, выводы
  SOURCES.md           откуда взяты данные
  ANSWERS.md           ответы на вопросы для защиты
  src/                 программа
  tests/               проверка контрольного варианта 0
  data/                исходные данные (модель IRI)
  results/             таблицы и графики
dz2/ ... dz6/          следующие задания - так же
```

## Как запустить

Из корня репозитория:

```
pip install -r requirements.txt
python dz1/src/solution.py --dz dz1 --variant 10 --save
pytest
```

Все команды задания - в его README.
